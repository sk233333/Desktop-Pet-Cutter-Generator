# Little-figurine-rating — 手办照片转 2D 桌宠素材

把白底手办照片自动抠成**带透明通道的桌宠素材**（PNG + 无损 WebP + manifest），
供 PyQt / Electron / 网页桌宠直接使用。

> 原「瑕疵检测」工程已整体移除；本仓库只保留抠图工具与桌宠运行时。手办素材（源图、mask、标注、生成产物）因版权与体积原因不入库，需自备，见 [docs/ASSETS.md](docs/ASSETS.md)。

---

## 一、目录

```

├── desktop_pet/
│   ├── launch.py              一站式：选图 -> 框取 -> 生成素材 -> 启动桌宠（默认图形界面，--cli 走命令行）
│   ├─ ui_app.py              PyQt6 单窗口操作界面（框取/补点/预览/多边形眼眶全在一个窗口里）
│   ├── cutout_to_pet.py       白底图 + mask -> 透明素材包
│   ├── anim.py                通用动作层：呼吸/摇摆参数、自动找眼、眨眼帧、表情差分贴片
│   ├── expr_state.py          表情状态机：半眼/惊讶/单侧眨眼，idle 随机触发
│   ├── effect_director.py     待机效果编排：mood 权重 × 表情/视线/气泡组合
│   ├── effect_table.json      mood 与效果权重表（可直接改，改完重启生效）
│   └── 逐素材覆盖：manifest 里可写 "effects": {"enabled": [...], "mood": "sleepy"}

│   ├── action_bridge.py       本机动作桥：双击/右键/对话 action → 启动程序（白名单）
│   ├── pet_window.py          PyQt6 透明置顶窗口：拖拽 + 呼吸摇摆 + 随机眨眼 + 表情
│   ├── source/<sku>/          抠图源：<stem>.png + <stem>_mask.png + 可选 .json / _eyes.json / _eyes.png
│   └── assets/<sku>/          生成产物：<stem>.png / .webp / _preview.png / manifest.json
└── Punctuation_selection_of_images/
    ├── image_assist.py        批量抠图/白底生成工具（SAM + YOLO）
    ├── image_assist_ans/      白底图输出（本地生成，不入库）
    └── sam2.1_hiera_small.pt  SAM 权重（本地放置，不入库）
```

`desktop_pet/source/`、`desktop_pet/assets/` 与 `image_assist_ans/` 均不入库：素材需自备，说明见 [docs/ASSETS.md](docs/ASSETS.md)。

## 二、快速开始

```bash
# 依赖：opencv-python、numpy、Pillow；可选 pymatting（边缘更干净）
pip install opencv-python numpy Pillow pymatting

# 生成全部素材
python3 desktop_pet/cutout_to_pet.py --sku bgy

# 只处理一张，并输出棋盘格预览
python3 desktop_pet/cutout_to_pet.py --sku bgy \
  --stem bgy_001_white --size 512 --preview

# 换尺寸 / 换输出目录 / 不用 matting
python3 desktop_pet/cutout_to_pet.py --sku bgy --size 768
python3 desktop_pet/cutout_to_pet.py --sku bgy --out-dir /tmp/pet_assets
python3 desktop_pet/cutout_to_pet.py --sku bgy --no-matting
```

新增 SKU：把白底图和对应 `_mask.png` 放进 `desktop_pet/source/<sku>/`，再跑 `--sku <sku>`。
没有 mask 时脚本会退回「非白像素」估计，但边缘质量会下降。

### 一条命令：选图 → 框取 → 选点 → 预览 → 多边形眼眶 → 多边形发缕 → 桌宠

```bash
pip install PyQt6 opencv-python pillow numpy matplotlib

python3 desktop_pet/launch.py                    # 弹文件选择框，随后五步交互
python3 desktop_pet/launch.py --image photo.jpg
python3 desktop_pet/launch.py --image photo.jpg --box 120,80,900,780 --no-points --no-preview --no-eyes
python3 desktop_pet/launch.py --image photo.jpg \
  --eyes-boxes "150,200,320,300;400,210,560,310"   # 原图坐标，直接跳过眼眶标注（--cli 旧路径）
```

`--cli` 会依次标出「第 x / 5 步 · 这一步要做什么」
（图形界面只把框取与抠图算必做，后三步都在右侧当「选做步骤」；
`--cli` 的眼睛步骤仍保留旧的拖框 / `--eyes-boxes`，不落 mask，也没有发缕这一步）：

1. **框取手办**：拖拽出框或左键点两个对角（点第一个角会显示黄点）；`r` 重框、`u` 撤销、`f` 整张图；回车继续
2. **选点**：左键 = 前景(红)、右键单击 = 背景(蓝)（右键拖动 = 平移图片），帮 SAM 纠正；`r` 全部清空、`u` 撤销、`s` 不补点；回车分割
3. **预览分割**：四联预览（原图+框 / Mask / 绿色叠加 / 白底图）；回车采用，`a` 返回补点重算，`ESC` 取消
4. **多边形眼眶**：左键沿眼眶边界逐个点顶点，回车或点「闭合眼眶」闭合当前眼眶；
   右键/中键按住可拖动图片（放大后用来平移）；闭合后可继续点下一只，没有未闭合多边形时再按回车完成；`u` 撤销、`r` 重来、`ESC` 取消。
   落盘 `<stem>_eyes.png`（R=眼1、G=眼2、B=高光），同时写一份外接框 `_eyes.json` 做兼容
5. **多边形发缕**（可跳过）：左键沿一缕头发的轮廓点一圈，**第一个顶点=发根**，
   回车或点「闭合发缕」闭合；右键/中键按住可拖动图片；可继续画下一缕，再按回车完成；`u` 撤销、`r` 重来、`s` 跳过。
   落盘 `<stem>_hair1.png…`（灰度 mask）和 `<stem>_hair.json`（发根/发梢坐标）

眼睛是逐只生效的：只画左眼就只眨左眼；一只都不画就不眨眼也不跟随视线；只有加
`--no-eyes` 时才完全不写标注、交给启动时自动检测。

`--no-preview` 可在批量/无头场景跳过第 3 步预览；`--no-points` 跳过选点，`--no-eyes` 跳过眼眶标注。

掩膜引擎：背景接近白色直接走非白阈值（不加载 SAM）；否则优先 SAM（`--engine sam`，
权重缺失或失败回退 `--engine grabcut`，`--device cpu` 可强制 CPU）。
生成后合成白底图存到 `source/<sku>/`，透明素材写到 `assets/<sku>/`，
最后自动弹出桌宠窗口（`--no-launch` 只生成）。

### 图形界面（单窗口）

```bash
python3 desktop_pet/launch.py        # 不带参数默认就是图形界面
python3 desktop_pet/launch.py --cli  # 要原来的命令行多窗口流程
```

界面里所有交互都收进一个窗口：

- 左侧是画布：滚轮/触控板以鼠标为中心缩放、中键拖动平移，画布上方还有一条
  `－ / 百分比 / ＋ / 适应窗口` 的缩放条（放大后眼球、发丝细节都能看清）；
  框选/剪切阶段画布右边是**白底预览**（把抠图成品合成到白底上，看边缘干不干净），
  白底预览同样支持**滚轮放大、左键拖动平移、双击复位**；点「保存」进入眼睛/头发步骤后
  右侧预览自动收起，只留一个主窗口
- **每一步上方都有按钮**（`确认 / 完整框 / 撤销 / 重来 / 跳过 / 取消`），框取、补点、
  眼眶、发缕都能纯鼠标操作；键盘 `回车 / u / r / s / f / ESC` 仍然等价可用
- **「开始处理」只做抠图**：框取手办 → 先确认框大小 → 补点（可直接跳过）→ 估计掩膜；
  **剪切结果预览左边显示框选出来的原图（绿色虚线 = 剪切范围 + 绿色半透明 = 保留下来的区域），
  右边白底预览抠图效果**；工具条上有「边缘 − / 档位 / 边缘 +」，共 0~3 档：
  **它不是整图锐化，只处理切割出来的轮廓**——窄带内让轮廓线更实、alpha 过渡收窄，
  2 档起还会把抠图常吃掉的发丝/尖角补回 1px，剪影更饱满；画面内部一个像素都不动。
  档位只在这一步「生成素材」时传给抠图管线（matting 之后作用于 alpha 与轮廓色），
  源图 <stem>.png 与掩膜 <stem>_mask.png 本身不会被改写
- **每个保存步骤都有「回退 (u) / 保存 (s) / 取消」按钮**（框大小确认、剪切结果、眨眼、头发飘动）：
  `s` 保存并进入下一步、`u` 回退到上一步重做、`取消` 放弃；**预览里不再用回车确认**
- **抠完手办后在画布正中按本来大小显示桌宠**（显示高度取自齿轮「设置」里的「显示高度」，0=自动），
  并左右轻微摇摆；画布上的这只桌宠是逐帧渲染的：**眼睛跟着鼠标看、按时间轴眨眼、发缕随风飘**，
  标完眼睛 / 发缕当场就能看到效果，不用先生成。**点图标栏的「眼睛」或「头发」时暂停摇摆**，方便看细节，
  眨眼 / 目光 / 飘发照常；一次任务结束后自动恢复摇摆
- **框取完成后先播「确认标框大小」预览**，`u` 重新框选、`s` 保存；
  保存后画布只显示框内内容，补点 / 眼睛处理 / 标注发缕都在这个裁切画面上，不会再退回整图
- 框取：拖拽出框或左键点两个对角（首点显示黄点），回车确认，`r` 重框、`u` 撤销、`f` 整图、`ESC` 取消
- 补点：左键 = 前景(红叉)、右键单击 = 背景(蓝叉)（右键拖动 = 平移图片，不会落点），直接回车 = 不补点，`r` 清空、`u` 撤销、`s` 跳过
- **补点精修放在剪切结果之后**：在剪切结果预览里点「回退」回到裁切画面继续补点、重新分割，
  不再单列成一个按钮；点「保存」采用当前结果（回退时会先把底图恢复成裁切原图，不会丢背景）
- **补点只统计绿框内的点击**，框外点击会被忽略并提示（因为掩膜最终按框裁剪）；想让某块背景被排除，先把框盖住它再打蓝点
- 有补点时以「点是否被满足」挑 SAM 候选：框画得很大（超过半幅图）会自动改成只用点提示、框只做裁剪，避免 SAM 把整幅图当成一个物体
- 画布与右侧面板之间有一条竖排图标栏（动作参数 / 衣服 / 眼睛 / 头发 / 小桌子 / 保存素材 / 桌宠空间，悬停有提示；
  第一个「动作参数」直接打开设置里的动作常数，保存素材用常用软盘图标，
  最后的小房子打开桌宠空间），
  点「衣服」「眼睛」「头发」切换右侧面板（只显示选中的那块），
  三个面板里的步骤**可任意顺序、重复执行**，也都可跳过：
  - **眼睛面板**（标注与眨眼合并成一张「眼睛处理」卡片，从上到下依次是）
    - **当前档位**：下拉选 `自动 / L2 / L1 / L0`，画下一只眼就按它打标；同一张图里可以逐只混用
    - **鼠标跟踪 / 眨眼**：两个勾选框，默认都开。取消「眨眼」会完全不闭眼（时间轴整块置灰），
      取消「鼠标跟踪」眼睛就定住不动；两者都会写进 `_blink.json`（`on` / `gaze`）并带到桌宠，
      预览与生成后的桌宠行为一致。只标注一只眼也照样有眨眼和看着鼠标的效果
      （单眼素材的 L0/L1 位移会上调到 2.4px，保证肉眼能看出来）
    - **表情**：桌宠会隔 3.5~11 秒随机来一下 **半眼 / 惊讶 / 单侧眨眼 / 眨眼**，
      用的是从同一套眼睛分层生成的差分贴片（`expr_state.py`，整块盖住眼睛、不重影）。
      半眼是**遮挡式**：眼球零形变，把上眼睑（原 lash 层）下移盖住上半部，
      眼环 / 高光 / 虹膜分界都不会被压扁；惊讶也只放大虹膜，眼白盘与眼睑不动。
      入口在桌宠**右键菜单 → 表情**：可以关掉「随机表情」，也可以直接点
      「半眼 / 惊讶 / 左眼眨一下 / 右眼眨一下」立刻试一个。
      眨眼与视线仍走原来的时间轴/跟随逻辑，两套互不干扰；没有眼眶 mask 的素材不启用
    - **待机编排（EffectDirector）**：`effect_table.json` 里定义 `calm / curious / sleepy`
      三种 mood 与各效果的权重，运行时按权重抽一个效果，同时驱动**表情 + 视线 + 气泡**
      三个通道（比如 sleepy 会慢眨眼 + `Zzz`、curious 会瞥一眼 + `?`）。
      同一效果不连播，用户刚摸过桌宠 3 秒内不打断，mood 切换有 20~40 秒冷却；
      表不存在时自动退回纯随机表情。效果只是组合已有通道，不增加任何新贴片
    - **眼睛处理**：左键沿眼眶边界逐个点顶点，回车或点「闭合眼眶」闭合；闭合后可继续点下一只，
      没有未闭合多边形时回车完成；**右键（或中键）按住可拖动图片**，放大后用来平移到要标的眼睛；
      `u` 撤销、`r` 重来、`ESC` 取消。标完直接保存并应用到中间的桌宠（不再单独播眨眼预览）
    - **眨眼时间轴**（同一张卡的下半部分，用分节线隔开）：**一行一只眼**，列依次是
      眼睛 / 当前档位 / 时刻 (s) / 闭眼时长 (s)（没有「眼睛数量」列，每只眼自己算自己的）。
      **初始是 0 行**；标注时每闭合一只眼眶，下面就自动多一行（时刻默认 2.0s 起步、
      多只依次错开 0.8s），删掉眼眶时对应行也会同步消失；
      **当前档位按眼逐只写**，如 `L1-1`（1、2 默认是左右眼，第三只眼写 `L1-3`；
      `自动` 表示按眼睛层级判定）。标完眼眶点保存后按实际眼睛填成 `L1-1`、`L2-2` 这样的条目。
      档位 / 时刻改完即时生效：中间那只桌宠会按时间轴循环眨眼，没有单独的「预览眨眼效果」步骤；
      生成后的桌面桌宠按同一套设置眨眼，勾选「鼠标跟踪」时眼球会跟着桌面上的光标走
  - **头发面板**
    - **标注发缕**：左键沿发缕轮廓点一圈（第一个顶点=发根），回车或点「闭合发缕」闭合；
      右键/中键按住可拖动图片（放大后用来平移）；可继续画下一缕，再回车完成；`u` 撤销、`r` 重来、`s` 跳过。完成后进入
      **头发飘动效果预览**：`u` 回退重画、`s` 保存
  - **衣服面板**
    - **标注衣物 / 小物件**：和发缕完全一样的画法——沿衣摆、袖子、挂饰等会飘的轮廓点一圈
      （第一个顶点=固定端），回车或点「闭合衣物」闭合；可继续画下一块，再回车完成；
      `u` 撤销、`r` 重来、`s` 跳过。完成后进入 **衣服飘动效果预览**（`u` 回退、`s` 保存）
    - **衣物列表**：每块一行（点一行在桌宠上亮起蓝色流光）；「删除选中 / 清空」随时改
    - 衣服与头发共用同一套飘动物理（速度 / 摆幅 / 刚度 / 阻尼），
      落盘为 `<stem>_cloth.json` + `<stem>_cloth1.png`，不标注就不做衣摆飘动
  - 点「衣服 / 眼睛 / 头发」会把对应面板滚到可视区；已标注的眼眶 / 发缕 / 衣物分别用
    蓝色 / 青色 / 橙色虚线描在剪切结果上，方便确认标的哪几块
- 竖条的**「小桌子」**是一个开关：抠完手办、画布上显示桌宠后点亮它，
  画布脚下会多一块木质平台（桌子腿撑在下面；宽度在动作参数的**「平台宽度」**里调，
  10%~2000%，默认 60%；滑条是对数刻度，前段调细、后段能一路拉到很宽）。桌宠和桌子都画在**同一个固定世界里**（世界坐标）：桌宠大小是
  固定的，**滚轮缩放只是镜头拉近拉远**，桌板和桌宠一起等比放大缩小、相对大小永远不变；
  改窗口大小同样只影响镜头。平台的世界宽度按「画布宽度 × 百分比」定一次
  （100% = 铺满整个画布，2000% = 画布 20 倍宽——视角缩到 5% 时也正好铺满；
  最窄也略宽过桌宠，免得被桌宠整个挡住），
  之后只有在拖「平台宽度」或换图时才重新定。
  桌宠先悬在平台正中心上方、
  再按重力落到平台上站住并继续摇摆；**只有开着小桌子时才有重力**，再点一次关闭
  （桌宠回到原位、平台消失）。
  **桌子模式下画布是张开/握紧的小手光标**：左键按住就能像桌面桌宠那样把它拎起来，
  左右拖到平台的任意位置、也能往上拎；**左右甩一下会顺着平台滑行**（阻尼和桌面版一致），
  滑到边缘外就顺势掉下去；松手后带着拖动速度继续落回平台（往上甩会先飞再落）。
  停住不动再松手不会乱甩。
  拖到平台边缘外再松手、或者在空中被拖出平台后落下，桌宠会**一路掉到画布底部**
  （掉出画面）**才跳回平台正中心**再落稳；
  往下拖不会穿过平台。右键 / 中键仍然平移画布。
  下落快慢在设置 → 动作参数的**「下落系数」**里调（0~3.0×，0 = 悬在桌面上方不落）；
  平台宽度在**「平台宽度」**里调（0.1~20.0，占画布宽度的比例，默认 0.6 = 半个多画布，
  1.0 = 铺满整个画布，20.0 = 画布 20 倍宽（5% 视角下也铺满），开着桌子时拖动立刻生效，
  并按新宽度重新定一次世界尺寸）；
  落到桌面的反弹在**「回弹系数」**里调（0 = 直接停住不弹，0.45 默认弹几下，1 = 原速弹回），
  甩下来弹几次就自然停稳；
  换图 / 重新标注会自动关掉小桌子
- **本机动作（ActionBridge）**：右键菜单最上面会列出配置好的动作（如「打开微信」「打开计算器」），
  双击桌宠只执行绑定的动作（没绑定就什么都不做）；**暂停/继续在右键菜单里选**。动作只认 `action_id`，从不接受路径字符串；
  启动用 argv 列表 + `startDetached`，不拼 shell；未知 id 静默忽略；关闭类动作默认要二次确认；
  带 `single_instance` 的动作已在运行就只给提示、不重复拉起；桌宠退出不会顺带关掉它启动的程序。
  配置分两层：每只桌宠的 `assets/<sku>/actions.json` 决定「有哪些动作」，
  用户自己的 `~/.config/desktop_pet/actions.json` 补真实路径 / 打开开关 / 绑定手势（不进仓库）。
  右键 **「动作设置…」会打开图形界面**（不用手改 JSON：`.json` 常被浏览器接管、直接打不开）：
  里面可以选程序、勾「双击触发」、勾「启用动作」，保存后立刻生效，不用重启桌宠。
  `enabled` 默认 false，第一次要在对话框里勾上。
  反馈显示在桌宠头顶的小气泡里，并顺带触发一个表情
- 不标注也能直接生成：眼睛位置用自动检测，没有发缕 / 衣物就不做飘动
- 刷新剪切结果不影响已落盘的标注；换图会清空上一次的抠图状态
- 日志会打印实际走的引擎（SAM / GrabCut）、补点数量、候选分数和掩膜覆盖率，点没起作用时一眼能看出原因
- 主界面顶部、标题「准备就绪」右边的齿轮按钮打开**设置**（SKU、素材名、边长、显示高度、引擎与设备，以及**动作参数**：
  头发飘动速度 / 摆幅 / 回弹刚度 / 回弹阻尼 / 摇摆角度 / 摇摆速度 / 回弹系数 / 下落系数 / 平台宽度）。
  每项都是**拖动条 0~3.0×**（0 = 停止，摇摆角度是 0~8°），

  下一次生成就用新值；动作参数还会即时作用在画布上的桌宠，并随素材写进 manifest，
  桌面桌宠也按同一套参数飘发、摇摆
- 画布上方有一条**任务长条**：跑框取 / 抠图 / 生成时显示，干完填满后自动收起
- 「图片」卡片带选中图片的缩略图，方便确认这次处理的是哪张图
- 档位在时间轴里按眼逐只写（`L1-1`、`L2-2`），生成时按「第几只眼」直接换成

- 一切就绪后点「生成素材并启动桌宠」；勾选「生成后启动桌宠」会直接弹出桌宠窗口，

  （不同素材仍可多只同屏）；取消勾选则只生成到 `assets/<sku>/`
- 点竖条最后的小房子图标（**桌宠空间**）会弹出独立窗口（大缩略图），自动列出 `assets/<sku>/manifest.json`
  里已生成的桌宠：**点图片就直接把这只召唤到桌面**（同一只已在桌面会先替换）；每张卡片上的
  「删除」会先弹确认，确认后把生成的 PNG/WebP/预览图**移入回收箱**并从 manifest 移除，

- 桌宠空间支持**批量删除**：点顶部「批量删除」进入勾选模式，缩略图变成可勾选的方框，

  **不改素材文件名**（`eyes_mask` / 发缕 mask 仍指向原文件），改回原名会删掉该字段

交互增强（都需要眼睛位置，自动检测不可靠时会自动跳过）：

- **视线跟随**：把「虹膜 + 瞳孔」当成一个整体（眼球）在固定的眼眶窗口里平移，眼眶 / 眼睑 / 睫毛轮廓不动。
  眼白的宽窄变化是平移的自然结果，不另画：眼球往左 → 左边眼白变窄、右边变宽；往下 → 下边眼白变窄。
  高光钉在原位，不跟视线走（跟的是光源）；两只眼各自朝鼻侧微收（位移的 20%，上限 2px）。
  偏移随鼠标距离做 smoothstep 缓入，再按 0.18s 时间常数逐帧缓动，不会一帧跳到位
- **L2 分层贴片**：把虹膜按**任意形状**从原图抠成贴片整体平移，不做径向重建，
  星星 / 十字 / 心形瞳纹原样保留。下→上依次是：挖空底图 → **全实心眼白盘**
  （原图打底、只把虹膜足迹填平，所以静止到移动不会整眶变暗）→ 虹膜贴片 → 高光
  （默认钉死）→ 睫毛 / 眼睑（不动，负责遮住眼球上缘）。实心眼白盘保证贴片怎么平移
  都不露底。位移上限按 `min(0.6*r_iris, 0.8*眼白余量, 6px)` 自动定，眼白余量 <1.5px
  时这只眼静默不跟随、只保留眨眼。启动时构建一次（约 4ms/眼），运行时每只眼 3 次
  `warpAffine` + 3 次 alpha 合成（约 0.4ms）
- **L1 / L0 整块微移**：用**位移场形变**，以手工绘制/自动检测的眼眶 mask 作为「容器」
  （眶外像素权重直接为 0，眉毛、睫毛根、脸颊皮肤不会跟着一起平移），眶内按彩度判据
  取出**像素级虹膜 mask**（不拟合椭圆——动漫虹膜是「圆盘被上眼皮切掉一块」的 D 形，
  椭圆拟合必然圆心偏下、短半径偏小，虹膜会看着贴在睫毛上往上飘）→ 距离变换生成位移
  权重（虹膜内部≈1 表现为刚体平移，到眼眶边界衰减为 0 使轮廓不动）→ `cv2.remap`
  按权重整体重采样，眼白靠拉伸吸收位移；手工标注的高光按「低饱和 + 够亮」找块后
  原样贴回（只按亮度会漏掉被阴影压暗的白色高光），自动检测的眼跳过这一步
- **单击反应**：原地弹跳（先挤压再拉伸的衰减振荡）并连眨两下
- **拖拽甩动**：拖动时按每帧位移估速，松手后按该速度惯性滑行，水平阻尼衰减
- **落地回弹**：开启时松手就受重力（1500 px/s²）落向任务栏上沿，触地反弹系数 0.45，
  落地瞬间带一次轻微挤压；撞到屏幕左右边缘同样反弹。关掉后原地停住，可以摆到任意高度
- **头发飘动**：按手工多边形圈出的「发缕」做**沿发丝渐变的剪切位移场**（发根权重 0、
  发梢权重 1，方向垂直于发丝），像素被连续拉伸而不是整块搬走。位移场只改采样位置、
  整图只采样一次，并在发缕边界平滑归零：不会「抠出→变换→叠回」把同一根发丝画两遍
  （重影的来源），也不会空出分界线。预乘 alpha + `BORDER_REPLICATE` 也不会
  在边缘掺背景色或变薄。外缘临透明的发缕摆幅 14% 发缕长度（上限 8px），
  压住脸/身体的 10%（上限 5px，往里的一半再收 60%）。
  驱动是被动的：拖拽速度、身体摇摆、落地冲击（`kick`），再叠加每缕不同相位的
  0.4Hz 左右微风；每缕阻尼/相位错开，不会整片头发同步晃
- **相互碰撞**：`--count` / `--stems` 启动多只时，所有窗口共用一个动画定时器，
  每帧按手办主体（不透明像素包围盒，不含窗口透明边距）两两检测：
  左右相挤互相推开并带一点弹性；从上方砸到另一只会被弹起并横向滑开，不会叠罗汉；
  拖动中的那只视为被抓住，只推开别人，自己不被推开
- 虹膜几乎填满眼眶、中间是白色大瞳孔的玩偶眼（居中的亮块按瞳孔而不是镜面高光处理）：
  虹膜本体不动，只让瞳孔连带外圈描边在虹膜内部滑动；瞳孔原位用最近邻填洞
  补成平滑虹膜，所以滑走的方向清楚、原位也不会剩下一圈暗环
- 虹膜位移上限由「虹膜边缘到眼眶边缘的实际余量」推出：
  `min(0.6×等效半径, 0.7×最大一侧余量 + 1.5px)`，没有眼白的 Q 版大眼余量≈0，
  位移自然收敛到 1.5px；窗口侧再加一层 `0.55×半径` / 素材短边 2% 的总上限，
  避免顶到眼眶边缘出现斗鸡眼/翻白眼
- 手画眼眶的虹膜边界会再吸附一次：种子只看色相/彩度判「是不是同一块虹膜」，不按明暗切，
  所以上深下亮的渐变虹膜不会被拆成「深色虹膜 + 亮色眼白」；眼白、贴上缘的深色眼睑/睫毛、
  中间的高光都按颜色种子排掉，再用四条断言（面积占比、彩度对比、混入眼白比例、
  中心是否贴眶沿）校验。任何一条不过就退回整块微移，宁可不挪，也不把眼白/眼睑一起拖走
- 眶内余量 `room < 1.5px`（虹膜顶满眼眶、星形瞳等）时这只眼**直接不参与视线**，
  只保留眨眼——宁可不动，也不要把整圈眼白拉成一条变形带
- 虹膜 mask 取不到（眶内没有彩度够的块）时，自动椭圆框跳过这只眼，不再退回「眼框中心
  0.45×短半径的小圆盘」（那会把睫毛/眼线当成眼球，看起来像翻白眼）；手画眼眶因为还有
  眶内距离场可用，改成退回整块微移
- 自动检测的眼（框圈的是整只眼 + 眼睑）不套用余量规则：眼眶往内收 0.84 当眼睑，
  按 `0.6×半径` 平移，并跳过瞳孔/高光拆分，避免把眼睑外圈当成瞳孔一起搬走
- 自动检测把大块头发当成眼睛（`rx` 超过素材宽度 12%）时，视线跟随自动停用；
  眯着的那只眼（`ry < 0.3·rx`）不参与视线

### 眼睛位置不准时（手工多边形眼眶）

## 四、脚本做了什么

1. **掩膜清理**：去掉小碎片，保留主体与足够大的配件
2. **alpha 估计**：优先 `pymatting`；缺依赖时用「腐蚀/膨胀带 + 高斯羽化」
3. **去白边**：按 `C = a·F + (1-a)·白` 反解前景色，扣掉白底混进边缘的白
4. **裁边**：裁到内容边界并保留 `--margin` 透明边距
5. **预乘缩放**：在预乘 alpha 空间缩放到 `--size`，避免半透明边缘被背景污染
6. **导出**：透明 PNG、无损 WebP、可选棋盘格预览、`manifest.json`

`manifest.json` 每个条目包含：`width/height`、`scale`、`anchor`（脚底中心，左上角原点）、
`coverage`、`alpha_mode`、`mm_per_px_canon`（如有）；若源目录里有 `<stem>_eyes.json`，
眼睛坐标会随裁边与缩放换算后写入 `eyes`；若还有 `<stem>_eyes.png`（眼眶 mask），
mask 会按最近邻随裁边/缩放搬到素材分辨率，文件名写进 `eyes_mask`，窗口优先用 mask 驱动视线。

## 五、已知限制

- 单张照片没有背面/被遮挡部分的像素，大幅动作需要 inpainting 或分层绑定
- 白底边缘的半透明发丝、耳尖在无 `pymatting` 时会略硬，装了会更自然
- mask 若把投影也包含进去，会带出一片暗边；需要重新分割或单独做阴影层
- 素材本身是静态图；呼吸与摇摆由实时几何变换生成，眨眼靠自动找到的一对眼睛局部覆盖肤色
- 眨眼检测依赖暗色眼线：浅色瞳孔、被刘海遮住或侧脸时检测不到；此时用 `--eyes-only` 画多边形眼眶 mask，或窗口自动跳过眨眼
- 眼睛这个尺度上 SAM 的点提示常把睫毛/眼线/泪痣当成一只眼，所以眼眶改为手工多边形（不跑 SAM）；多边形小于 3 个顶点时不会生成 mask
- 窗口是矩形命中区，完全透明的角落也会响应拖动；Wayland 合成器不允许客户端定位窗口，
  启动时会自动改走 XWayland（xcb）以保留拖动甩动/落地回弹；`QT_QPA_PLATFORM=wayland` 可强制原生 Wayland（此时无落地回弹）
- `launch.py` 默认用 SAM；权重缺失或手动 `--engine grabcut` 时适合纯色/简单背景，复杂背景、发丝与半透明边缘仍建议先用 `image_assist.py` 抠图再转素材

## 六、收敛边界（渲染状态）

- **唯一状态源**：`arbiter.resolve()` 决定 blink / expr / gaze / bubble；所有写入走
  `arbiter.request()`，时间轴相位由 `timeline_phase()` 产出后喂 `set_timeline_blink()`。
- **眨眼**：默认 `half:false` 走 `make_blink_frames` 的 0.55 遮挡过渡帧 → 全闭帧；
  `half:true` 的前半段改用 `ExprBank.apply(base,"half")`。`dt == hold/2` 归全闭。
- **全闭眼只有一份实现**：`frames[-1]`（时间轴与 idle 随机眨眼共用）。
- **未收口（已知差异，不是缺陷）**：右键「单眼眨一下」的 `wink_l/wink_r` 与编辑器
  预览的 blink 贴片仍走 `ExprBank`；它们与整帧 `frames[-1]` 观感略有差别。
- **眼睛过滤**：`active_eye_parts` 只决定哪些 `eye_index` 参与通道，不重编号；
  `mask=null` 是硬约束，白名单只能救回 `group=null`。
