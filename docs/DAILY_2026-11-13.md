## 解决

1. 默认路径改回 `frames[0] → frames[-1]`，`half:true` 才插 `ExprBank` 半闭；docstring 的「压缩帧」措辞一并订正。
2. 归一化只放在 `read_manifest()`，`Blink` 内部把旧 int 调用转成 `g{n}`，下游只见字符串。
3. `_derive_legacy()` 由 parts/timeline 反推旧字段，迁移写盘与运行读取是同一套值；再加 `legacy_consistent()` 逐项自检。
4. 白名单收紧为「只救 group=null」，mask=null 硬约束；启动 warning + `--check` 的 `[pending 需补 mask]` 让未生效状态持续可见。
5. C8e / C8e-b 分成两条：前者断言 `gaze_geos()==[]`、`expr_bank() is None`、整帧逐像素等于 base；后者覆盖 blink 通道。
6. Release 用编辑补一句说明，不重发、不动 tag。
7. 补 MIT LICENSE 与 THIRD_PARTY_NOTICES（依赖 / 权重 / 素材三层）；权重移出索引并删 `.gitattributes`，filter-repo 重写历史重建 tag，full clone 降到 40M。
8. README 首屏加历史重写公告，明确「重新 clone、旧 hash 失效、内容未变」。

## 反思

- **实现纠正了文档，也要回写文档**：0.55 帧和 v1 措辞都是我先按错误前提写文档、后被实测推翻；只改代码不改文档，下一个人会照着旧文档改回去。
